# Scripts

Все скрипты запускаются из корня монорепозитория через `pnpm <script-name>`.

---

## Gateway

| Скрипт              | Команда                       | Описание                                                                                 |
| ------------------- | ----------------------------- | ---------------------------------------------------------------------------------------- |
| `gateway:build`     | `nest build gateway`          | Компилирует приложение в `dist/apps/gateway`                                             |
| `gateway:start`     | `node dist/apps/gateway/main` | Запускает скомпилированное приложение (production)                                       |
| `gateway:start:dev` | `nest start gateway --watch`  | Запускает приложение в режиме разработки с hot-reload. Переменная `NODE_ENV=development` |

## User Accounts

### Приложение

| Скрипт                    | Команда                             | Описание                                                                                                                                                        |
| ------------------------- | ----------------------------------- | --------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `user-accounts:build`     | `nest build user-accounts`          | Компилирует приложение в `dist/apps/user-accounts`                                                                                                              |
| `user-accounts:start`     | `node dist/apps/user-accounts/main` | Запускает скомпилированное приложение (production)                                                                                                              |
| `user-accounts:start:dev` | `nest start user-accounts --watch`  | Запускает приложение в режиме разработки с hot-reload. Переменная `NODE_ENV=development`. Перед запуском автоматически выполняется `preuser-accounts:start:dev` |

> **preuser-accounts:start:dev** — pre-hook, срабатывает автоматически перед `user-accounts:start:dev`. Последовательно поднимает Docker-контейнер с БД, генерирует Prisma Client и применяет миграции.

### Docker

| Скрипт                      | Описание                                                                                                                         |
| --------------------------- | -------------------------------------------------------------------------------------------------------------------------------- |
| `user-accounts:docker:up`   | Поднимает контейнер с PostgreSQL (`snaptix-user-accounts-db`, порт `10000`) в фоне. Ждёт готовности контейнера через healthcheck |
| `user-accounts:docker:stop` | Останавливает контейнер без удаления данных                                                                                      |
| `user-accounts:docker:down` | Останавливает и удаляет контейнер                                                                                                |

### Prisma

> Скрипты с суффиксом `:dev` используют `NODE_ENV=development` и загружают `.env.development` через `prisma-wrapper.ts` перед выполнением команды Prisma.

| Скрипт                             | Описание                                                                                                                    |
| ---------------------------------- | --------------------------------------------------------------------------------------------------------------------------- |
| `user-accounts:prisma:generate`    | Генерирует Prisma Client по схеме `apps/user-accounts/prisma/schema.prisma`                                                 |
| `user-accounts:prisma:migrate:dev` | Создаёт и применяет новую миграцию (dev-окружение). Используется при изменении схемы                                        |
| `user-accounts:prisma:deploy:dev`  | Применяет существующие миграции без создания новых (dev-окружение). Используется при первоначальной установке или CI        |
| `user-accounts:prisma:deploy:prod` | Применяет существующие миграции в production. Запускается без обёртки — переменные окружения должны быть выставлены заранее |
| `user-accounts:prisma:studio:dev`  | Открывает Prisma Studio для визуального просмотра и редактирования данных (dev-окружение)                                   |

### Внутренние скрипты

| Скрипт                             | Описание                                                                                                                                                                                  |
| ---------------------------------- | ----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `user-accounts:prisma-wrapper:dev` | Вспомогательный скрипт. Загружает `.env.development` из директории приложения через `scripts/prisma/prisma-wrapper.ts`, затем выполняет переданную Prisma-команду. Не вызывается напрямую |

## Общие скрипты

| Скрипт       | Описание                                                            |
| ------------ | ------------------------------------------------------------------- |
| `build`      | Компилирует все приложения монорепозитория                          |
| `format`     | Форматирует `.ts`-файлы в `apps/` и `libs/` через Prettier          |
| `lint`       | Запускает ESLint с автофиксом для `src/`, `apps/`, `libs/`, `test/` |
| `test`       | Запускает unit-тесты через Jest                                     |
| `test:watch` | Запускает тесты в watch-режиме                                      |
| `test:cov`   | Запускает тесты с отчётом покрытия                                  |
| `test:debug` | Запускает тесты с подключением Node.js-дебаггера                    |
| `test:e2e`   | Запускает e2e-тесты для gateway (`apps/gateway/test/jest-e2e.json`) |
